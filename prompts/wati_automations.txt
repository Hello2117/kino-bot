# WATI Automation Rules
# Set these up in WATI Dashboard → Automation → Create Automation
# These run server-side in WATI without needing your webhook.
# ================================================================


## ────────────────────────────────────────────────────────
## AUTOMATION 1: BUSINESS HOURS AUTO-REPLY
## Trigger: New message received
## Condition: Current time is OUTSIDE business hours
## Action: Send template message
## ────────────────────────────────────────────────────────

Name: Outside Hours Reply
Trigger: Message received
Conditions:
  - Time is NOT between 09:00 and 18:00 (MYT, Mon-Sat)

Action: Send message
Message:
  Hi there! 👋 Thanks for reaching out to *TWENTYONESEVENTEEN*.

  We're currently outside business hours (9am–6pm, Mon–Sat).

  KINO will still try to help you right away! If you need to speak to our team directly, we'll get back to you first thing during business hours. 🎬


## ────────────────────────────────────────────────────────
## AUTOMATION 2: UNASSIGNED CONVERSATION ALERT
## Trigger: Conversation becomes unassigned (KINO handoff)
## Action: Send internal notification to all agents
## ────────────────────────────────────────────────────────

Name: Handoff Alert to Team
Trigger: Conversation assigned to "No Agent" (unassigned)
Action: Notify all agents (push notification + email)
Message to agents:
  ⚡ KINO has handed off a conversation.
  Customer needs human attention — please review in the inbox.


## ────────────────────────────────────────────────────────
## AUTOMATION 3: AUTO-CLOSE STALE CONVERSATIONS
## Trigger: Conversation has had no activity for 48 hours
## Condition: Conversation is still open
## Action: Send closing message + mark resolved
## ────────────────────────────────────────────────────────

Name: Auto-close Stale Conversations
Trigger: No activity for 48 hours
Conditions:
  - Conversation status = Open

Action 1: Send message
  Hi! 👋 Just checking — are you still looking to rent gear from *TWENTYONESEVENTEEN*?

  If you'd like to continue, just reply here and KINO will pick up right where we left off. Otherwise, we'll close this chat for now. See you on set! 🎬

Action 2: Wait 24 hours
Action 3: If no reply → Mark conversation as Resolved

## ────────────────────────────────────────────────────────
## TEAM INBOX SETUP IN WATI
## ────────────────────────────────────────────────────────

Step-by-step to add staff:
1. WATI Dashboard → Settings → Team Members
2. Click "Add Member"
3. Enter staff email address
4. Choose role:
   - Admin: Full access (manage settings, view all chats, send messages)
   - Agent: Chat access only (view assigned chats, send messages)
5. Staff receives email invite → they set a password → done

Conversation assignment:
- "Unassigned" pool = visible to all agents, anyone can pick up
- Assigned to specific agent = only that agent + admins can see
- KINO handoffs go to Unassigned automatically

Mobile access:
- Staff can download the WATI mobile app (iOS + Android)
- Full inbox access on mobile — get push notifications for new handoffs
